# 只有一個插座

繁體中文 2D 瀏覽器小遊戲。三分鐘的交件倒數，三台設備，只有一個插座。
使用 TypeScript + Vite + HTML/CSS，圖形由 CSS 繪製，無外部 API、字型或圖片依賴。

## 安裝與執行

需要 **Node.js 22.18 以上，建議 Node 24**，以及 npm。

### 先確認 Node 版本

```sh
node --version
```

若顯示 `v10.15.0` 等舊版本，必須先切換版本，否則 Vite 會出現 `SyntaxError: Unexpected token {`，無法啟動。

本機已透過 nvm-windows 安裝 Node 24.6.0，可在 PowerShell 執行：

```powershell
nvm use 24.6.0
node --version
npm run dev
```

`nvm use` 會切換這台電腦目前啟用的 Node 版本；若權限不足，請使用系統管理員終端機執行。若 IDE 終端機仍顯示舊版本，請重新開啟終端機再確認。
其他電腦尚未安裝此版本時，可先執行 `nvm install 24.6.0`。專案的 `.nvmrc` 記錄此版本；nvm-windows 請明確指定 `nvm use 24.6.0`。

### 安裝依賴並啟動

```sh
npm install
npm run dev
```

開啟終端機顯示的本機網址。已有 lockfile 的乾淨安裝可使用 `npm ci`。

```sh
npm test          # 遊戲規則與時間步進測試
npm run build    # TypeScript 檢查與正式建置
npm run preview  # 預覽 dist 建置結果
```

## 遊戲規則

- 在 180 秒內完成 100% 工作就獲勝；時間耗盡則失敗。
- 點擊設備，或按 1（電腦）、2（電風扇）、3（手機），立即切換唯一的供電對象。
- 電腦通電時工作，斷電時保留進度。室溫越高效率越低，最低仍有 20%。
- 電風扇通電時降溫，其他時候室溫升高。
- 手機通電時充電，其他時候耗電。工作到 30% 與 60% 時，各需要一份資料。
- 手機有電就自動接收資料（不必供電給手機）；沒電時工作會停在該門檻，明確提示先充電。資料接收不額外耗電。
- 切換分頁會自動暫停全部數值，回來後按「繼續上工」。亦可按「暫停」或空白鍵暫停。
- 結果畫面按「再挑戰一次」，重設時間、供電、進度、室溫、電量、資料接收與計時累積。

操作提示：不要等到過熱才開風扇；手機補充少量電量即可接收資料，掌握切回電腦的時機。

## 難度與程式結構

- `src/config.ts`：所有難度數值（秒數、工作速率、溫度、充放電、資料門檻）。
- `src/game.ts`：純遊戲邏輯，以經過時間驅動每秒 60 次固定步進，保留時間餘數，避免螢幕更新率改變難度。
- `src/main.ts`：DOM 介面、鍵盤操作、Page Visibility 暫停與重新開始。
- `src/style.css`：桌面、設備與響應式介面，支援減少動態效果偏好。
- `tests/game.test.ts`：可獨立執行的遊戲規則測試。

## 發布到 itch.io

1. 執行 `npm run build`。
2. 將 **dist 資料夾內的內容**壓成 ZIP，讓 `index.html` 直接位於 ZIP 根目錄，並保留 `assets` 資料夾。
3. 在 itch.io 建立 HTML 遊戲，上傳 ZIP，勾選瀏覽器內執行。
4. 建議嵌入大小 1120 × 860，允許全螢幕；手機使用直向版面。

Vite 已設定相對資源路徑 `base: './'`。不要直接雙擊 HTML，請透過 Vite 預覽或 itch.io 開啟。

## 人工驗收

自動測試涵蓋規則、勝敗、重設、不同畫面更新率與可獲勝策略。仍需在瀏覽器實際確認：點擊與鍵盤操作、等待提示、切換分頁後繼續、桌機／手機版面，以及 itch.io iframe 內載入與遊玩。難度與操作節奏需依實際試玩調整。
